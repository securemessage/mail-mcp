SecureMessage Mail MCP server for IMAP and SMTP email operations. Use mail_list_instances to see configured accounts. Use mail_connect to establish IMAP/SMTP connections before performing operations. All tools accept an optional instance parameter to target a specific account. Use mail_search with flexible filters (from, to, cc, subject, body, date range, read/unread, answered/unanswered, flagged, keyword) — it searches across all mailboxes by default. Use mail_create_draft to compose emails for review before sending. Use mail_move_message to organize emails into folders. Use mail_get_thread to view full conversation threads. Use mail_set_flags to manage labels and flags on messages.
